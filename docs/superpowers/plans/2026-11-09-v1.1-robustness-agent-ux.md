# gemini-image-api v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar el spec `docs/superpowers/specs/2026-11-09-v1.1-robustness-agent-ux-design.md`:
- rutas independientes del cwd y `copy_to`;
- motivo real del fallo de guardado;
- ciclo de vida del cliente que persiste cookies y no deja tráfico en reposo;
- cuota real con freno;
- `list_generations` y `gen:<id>`;
- ergonomía MCP para agentes (instructions, descripciones, enum, anotaciones, `retryable`/`next_action`);
- `styles.yaml` empaquetado y `mcp-config` correcto.

**Architecture:**
- Nueva capa `service.py` (`ImageService`) que concentra la secuencia prompt → refs → freno de cuota → backend → copy_to → payload. `cli.py` y `mcp_server.py` pasan a ser envoltorios finos.
- `client.py` sigue siendo el único módulo que importa `gemini_webapi`. Añade `quota()` y `aclose()` y gestiona el ciclo de vida del cliente upstream.

**Tech Stack:** Python ≥3.11, uv, `gemini-webapi==2.1.1`, fastmcp 4.1.7, typer, pydantic(-settings), pytest + pytest-asyncio (`asyncio_mode=auto`) + respx.

## Global Constraints

- `gemini_webapi` solo se importa en `src/gemini_image_api/client.py`. Comprobación: `grep -rn "gemini_webapi" src/ --include="*.py" | grep -v client.py` → vacío.
- Los tests NUNCA hacen red real a Google. El upstream se inyecta con `client_cls` o con los fakes de `tests/test_client.py`; httpx se mockea con respx.
- `output_root` por defecto: `~/Pictures/gemini-image-api` (sobrescribible con `GIA_OUTPUT_ROOT`).
- `GIA_QUOTA_STOP_PCT` por defecto `90`; `0` desactiva el freno.
- Auto-cierre del cliente MCP: `close_delay=900` s.
- Códigos de error: 19 exactos. A los 16 actuales se añaden `quota_guard`, `path_not_allowed` e `invalid_aspect`.
- `aspect_hint` admite exactamente `1:1`, `16:9`, `9:16`, `4:3`, `3:4`.
- `list_generations`: `limit` por defecto 20, máximo 100.
- Formato de referencia: `gen:<record_id>[#<index>]`, con `record_id` como `g_<12 hex>`.
- Un commit por task, con mensaje convencional. Código, identificadores, comentarios y mensajes de error en inglés. README en español.
- La suite completa (`uv run pytest -q`) debe quedar verde y sin warnings al final de cada task.

```python
    LIST_MAX = 100

    def generation(self, gen_id: str) -> GenerationRecord | None:
        return next((r for r in self.load_all() if r.id == gen_id), None)

    def list(self, *, query=None, project=None, since=None, status=None, limit=20, offset=0):
        records = self.load_all()
        deleted = {r.conversation_id for r in records if r.type == "delete"}
        q = query.lower() if query else None
        out = [r for r in records
               if r.type != "delete" and r.conversation_id not in deleted
               and (q is None or q in (r.prompt or "").lower())
               and (project is None or r.project == project)
               and (status is None or r.status == status)
               and (since is None or r.ts >= since)]
        out.sort(key=lambda r: r.ts, reverse=True)
        limit = max(1, min(int(limit), self.LIST_MAX))
        return out[max(0, int(offset)): max(0, int(offset)) + limit]
```

```python
        raise GIAError(INVALID_REF, f"generation {rec.id} has no image index {idx}")
    if not entry.get("path"):
```

```python
            if isinstance(pct, (int, float)) and pct >= stop:
                raise GIAError(QUOTA_GUARD, f"{pct_key} at {pct}% >= GIA_QUOTA_STOP_PCT={stop:g}",
                               quota=q, resets_at=q.get(reset_key))

    async def _run(self, call, *, prompt, refs, style, style_text, template, template_vars, aspect_hint,
                   copy_to) -> ServiceResult:
        final = build_prompt(self.catalog() if (style or template) else StyleCatalog(), prompt=prompt,
                             style=style, style_text=style_text, template=template,
                             template_vars=template_vars, aspect_hint=aspect_hint)
        target = check_copy_dest(copy_to, self.settings) if copy_to else None
        await self._guard()
        with tempfile.TemporaryDirectory() as td:
            resolved = await resolve_refs(list(refs or []), self.settings, Path(td),
                                          lookup=self.state.generation)
            res = await call(final, resolved)
        copies: dict[int, dict] = {}
        if target is not None:
            for i, img in enumerate(res.images):
                try:
                    copies[i] = {"copied_to": str(copy_file(img.path, target))}
                except OSError as e:
                    copies[i] = {"copy_error": f"{type(e).__name__}: {e}"}
        return ServiceResult(res, await self.backend.quota(), copies)

    async def generate(self, *, prompt, refs=None, style=None, style_text=None, template=None,
                       template_vars=None, aspect_hint=None, model=None, project=None, subdir=None,
                       copy_to=None, progress=None) -> ServiceResult:
        model = model or self.settings.default_model
        return await self._run(
            lambda final, resolved: self.backend.generate(
                final, resolved, model=model, progress=progress, project=project, subdir=subdir,
                style=style, style_text=style_text, aspect_hint=aspect_hint, slug_source=prompt),
            prompt=prompt, refs=refs, style=style, style_text=style_text, template=template,
            template_vars=template_vars, aspect_hint=aspect_hint, copy_to=copy_to)

    async def edit(self, conversation_id, *, prompt, refs=None, style=None, style_text=None, template=None,
                   template_vars=None, aspect_hint=None, model=None, project=None, subdir=None,
                   copy_to=None, progress=None) -> ServiceResult:
        model = model or self.settings.default_model
        return await self._run(
            lambda final, resolved: self.backend.edit(
                conversation_id, final, resolved, model=model, progress=progress, project=project,
                subdir=subdir, style=style, style_text=style_text, aspect_hint=aspect_hint,
                slug_source=prompt),
            prompt=prompt, refs=refs, style=style, style_text=style_text, template=template,
            template_vars=template_vars, aspect_hint=aspect_hint, copy_to=copy_to)

    def list_generations(self, **filters) -> list[dict]:
        return [{"id": r.id, "ts": r.ts, "type": r.type, "conversation_id": r.conversation_id,
                 "prompt": r.prompt, "style": r.style, "project": r.project, "status": r.status,
                 "images": [{"index": e.get("index"), "path": e.get("path")} for e in r.images]}
                for r in self.state.list(**filters)]


def to_payload(sr: ServiceResult) -> dict:
    r = sr.result
    images = []
    for i, s in enumerate(r.images):
        item = {"path": str(s.path), "width": s.width, "height": s.height, "bytes": s.nbytes,
                "format": s.format, "full_size": s.full_size, "index": i}
        item.update(sr.copies.get(i, {}))
        images.append(item)
    payload = {"status": r.status, "code": r.code, "conversation_id": r.conversation_id, "images": images,
               "gemini_text": r.gemini_text, "elapsed_s": r.elapsed_s, "quota": sr.quota}
    if r.status == "generated_not_saved":
        payload["details"] = {"reason": r.save_error}
    return payload
```
