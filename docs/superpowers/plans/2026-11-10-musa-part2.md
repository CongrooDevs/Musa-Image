# Musa parte 2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Implementar `docs/superpowers/specs/2026-11-10-musa-part2-full-design.md`. Musa queda como el diseño v6 completo: pantalla de carga al abrir, Inicio, compositor con cola real, Límites de uso con la cuota real de Gemini y detalle de colección completo. Nada ficticio.

**Architecture:**
- **Backend:**
  - `uploads.py`: subidas temporales.
  - `jobs.py`: cola de un solo worker sobre `ImageService`.
  - Endpoints nuevos en `webapp.py`.
  - `refs.validate_trusted_image` para las refs de confianza (estilo y subidas).
  - `StateStore.images_per_day`.
  - `LibraryStore.activity`.
  - `ASPECT_HINTS` con 10 proporciones.
- **Frontend:** se porta el resto del diseño en 3 pasos sobre los mismos `web/index.html`, `app.css` y `app.js`.

**Tech Stack:** Python 3.11, Starlette, asyncio, Pillow, vanilla JS. Tests con pytest y `TestClient`.

## Global Constraints
- Solo `src/gemini_image_api/client.py` importa `gemini_webapi`.
- Los tests nunca usan la red real.
- `uv run pytest -q -W error` debe quedar verde al final de CADA task.
- Un commit convencional por task. Cada agente añade al commit solo sus archivos (`git add <rutas>`), con `git -c user.name="diegoandresmc" -c user.email="diegoandresmc@localhost" commit`.
- Idiomas: código, identificadores y comentarios en inglés; la interfaz y el README en español.
- Los 22 códigos de error del agente no cambian. Los códigos nuevos son SOLO web y van en `webapp.WEB_NEXT_ACTION`: `queue_full`, `job_running`, `unknown_job`, `unknown_upload`.
- Nada ficticio: ni datos de ejemplo, ni botones sin función, ni progreso inventado (el progreso estimado se marca con «≈»).
- Nunca se trabaja con el estado real del usuario. Las pruebas manuales usan `GIA_STATE_DIR` y `GIA_OUTPUT_ROOT` en `/tmp`.

class UploadStore:

# jobs.py
@dataclass class Job: id, batch, prompt, style, model, ratio, refs (list[str] gen refs), uploads (list[str] ids),
                      collection, status ("queued"|"running"|"done"|"error"), created, started, finished,
                      record_id, images (list[str] keys), error (dict|None)
    def to_json(self) -> dict

    def __init__(self, service: ImageService, uploads: UploadStore, *, on_change: Callable[[], None] | None = None)

create_app(..., jobs: JobQueue | None = None, uploads: UploadStore | None = None)   # created inside if None
