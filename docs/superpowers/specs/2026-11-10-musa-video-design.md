
## 3. Modelo de vídeo — resultado de la prueba real (2026-11-10)

**No hay vídeo disponible en esta cuenta.**

- La cuenta registra solo `gemini-flash-lite`, `gemini-flash`, `gemini-pro` y `gemini-carbon`.
- Ningún id de Veo (`veo-3.1-fast`, `veo-3.1-generate-001`, `veo-3.0-…`, `veo-2.0-…`, `veo`) resuelve en el registro de la cuenta.
- `gemini-carbon` responde a un prompt de vídeo: «Direct video file generation isn't available right now…» y devuelve `videos=0`.
- `gemini-pro` también devuelve `videos=0`.

Conclusión: la suscripción web PRO no incluye generación de vídeo (Veo) a través de esta API. El subproyecto 3B queda **detenido** según el criterio aprobado: sin modelo que devuelva vídeo no se construye nada. Para activarlo haría falta una cuenta con Veo habilitado o la API oficial de pago.
